# belajar-evm

My notes from learning the Ethereum Virtual Machine (EVM) hands-on, written in Indonesian.
Most claims are checked against real chains (Ethereum, BSC) or a local `anvil` node, and each
note records the command and the result.

Start with [EVM 00 - Roadmap](EVM%2000%20-%20Roadmap.md), then read the notes in number order.
Detailed explanations for session 01 are in [`EVM 01 - Detail/`](EVM%2001%20-%20Detail/).

Tools used: [Foundry](https://book.getfoundry.sh/) (`forge`, `cast`, `anvil`).
