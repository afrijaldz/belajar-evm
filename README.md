# belajar-evm

Catatan belajar Ethereum Virtual Machine (EVM) sambil praktik langsung. Sebagian besar klaim
dicek ke chain sungguhan (Ethereum, BSC) atau node `anvil` lokal, dan setiap catatan menulis
perintah yang dipakai beserta hasilnya.

Mulai dari [EVM 00 - Roadmap](EVM%2000%20-%20Roadmap.md), lalu baca catatan sesuai urutan nomor.
Penjelasan detail untuk sesi 01 ada di folder [`EVM 01 - Detail/`](EVM%2001%20-%20Detail/).

Tools yang dipakai: [Foundry](https://book.getfoundry.sh/) (`forge`, `cast`, `anvil`).
